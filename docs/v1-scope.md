# 조합도우미 V1 범위 확정안

## 제품 목표

V1은 계정이나 공유 기능 없이, 사용자가 현재 보유한 유닛과 지정 특수 재료를 빠르게 입력하고 제작 가능한 조합과 부족 요소를 확인하는 단일 화면 도구로 만든다.

## V1 포함 기능

### 입력

- 흔함 유닛 빠른 입력과 단축키
- 한 페이지에 항상 노출된 등급별 전체 유닛 목록에서 입력
- 검색은 유닛을 숨기거나 별도 결과 화면으로 바꾸지 않고 대상 행을 강조하고 해당 위치로 짧게 이동시키는 보조 기능
- 수량 증가, 감소, 전체 초기화, 실행 취소
- 지정 특수 재료 입력
- 사용자가 특정 재료 또는 등급을 계산에서 제외하는 기능

### 조합 계산

- 보유 수량을 기준으로 제작 가능 조합 계산
- 직접 재료와 재귀적으로 환산한 최하위 재료 표시
- 부족 재료 수량과 제작 가능률 표시
- 지정 특수 재료가 조합에 필요하면 결과 카드와 재료 트리에서 강조
- 선택한 특정 재료 또는 등급은 해당 계산 세션에서 제외
- 제외된 요소 때문에 계산 결과가 달라지면 제외 적용 상태를 화면에 표시

### 전투 기여도 요약

- 현재 보유·조합 완료 유닛 기준 방어력 감소(방깎) 총합 표시
- 현재 보유·조합 완료 유닛 기준 이동속도 감소(이감) 총합 표시
- 유닛 증감과 조합 실행·취소 시 즉시 재계산
- 조건부, 범위형, 단일 대상 효과는 원본 조건을 보존하고 동일 조건끼리만 합산
- 수치가 아직 수집되지 않은 유닛은 `0`으로 취급하지 않고 `수치 미확인`으로 별도 표시

## 기타 재료 정책

기본 원칙은 목재, 골드 등 `기타` 재료를 입력과 조합 계산에서 제외하는 것이다.

아래 항목만 예외로 입력 목록에 노출하고 계산에 포함한다. 조합 필요 요소로 등장할 때 시각적으로 강조한다.

- 불사조의 깃털
- 슈스이
- 우타의 헤드셋
- 태양신의 흔적
- 특성포인트 x 4
- 그린블러드
- 레일리(재료용 ID 124)
- 고대의 배
- 해적선
- 좀비

요청 목록의 `그린블러드` 중복은 하나로 정리했다. `금 5,000`, `금 10,000`, `금 30,000`, `목재`, `랜덤전용유닛 1기`, `행운의 토큰` 등 나머지 기타 항목은 V1 계산과 입력에서 제외한다.

## V1 제외 기능

- 메모
- 로그인, 회원가입, 계정
- SAVE/LOAD 등 영구 상태 보존
- 로컬 자동 저장과 기기 간 동기화
- URL 또는 외부 채널을 통한 덱 공유
- 공개 클리어, 커뮤니티, 랭킹

새로고침하면 입력 상태가 초기화되는 세션형 도구로 시작한다. 실행 취소는 현재 세션의 메모리에서만 제공한다.

## 화면 구성

### 상단 요약 바

- 현재 보유 등급별 수량
- 방깎 합계
- 이감 합계
- 전체 초기화와 실행 취소

### 보유 요소 입력 영역

- 흔함 빠른 입력 키패드
- 현재 사이트와 유사한 조밀한 다단 등급 목록을 한 페이지에 모두 표시
- 가상 스크롤, 페이지네이션, 등급 탭 전환은 사용하지 않음
- 등급 헤더는 현재 위치를 쉽게 파악할 수 있게 유지하고, 전체 페이지의 세로 길이를 줄이도록 행 높이와 여백을 최소화
- 검색 시 다른 유닛을 숨기지 않고 대상 강조와 짧은 자동 스크롤만 수행
- `특수 재료` 섹션에 허용된 10개 항목만 표시
- 제외할 재료·등급 설정

### 가운데: 조합 후보

- `제작 가능`, `부족 1~2개`, `장기 목표` 그룹
- 부족 수량, 제작률, 방깎·이감 변화량 표시
- 지정 특수 재료가 필요하면 경고색 배지와 재료명을 표시

### 오른쪽: 재료 상세

- 선택 조합의 재귀 재료 트리
- 보유, 부족, 계산 제외, 지정 특수 재료를 서로 다른 상태로 표현
- 최하위 재료로 평탄화한 합계 보기 제공

## 계산 규칙

1. 입력된 보유 수량에서 사용자가 제외한 등급·재료를 먼저 제거한다.
2. 목재·골드 등 기본 제외 재료는 조합식에 존재해도 요구량과 부족량에 반영하지 않는다.
3. 지정 특수 재료 10개는 일반 유닛과 동일하게 요구량과 부족량에 반영한다.
4. 조합 후보별로 재료 그래프를 재귀 탐색하되 순환 참조를 감지한다.
5. 동일 재료는 경로별 요구량을 합산한다.
6. 지정 특수 재료가 하나라도 필요하면 후보 카드에 `특수 재료 필요` 상태를 부여한다.
7. 방깎·이감은 실제 적용 가능한 완성 유닛의 구조화된 효과값만 합산한다.

## DB 반영

- `units.input_visible`: 입력 UI 노출 여부
- `units.calculation_policy`: `include`, `exclude`, `user_selectable`
- `units.emphasize_when_required`: 조합 필요 시 강조 여부
- `unit_effects.effect_code`: `armor_reduction` 또는 `slow`
- `unit_effects.value`: 합산할 숫자값
- `unit_effects.value_unit`: 고정값, 퍼센트 등 단위
- `unit_effects.condition_text`: 보스, 범위, 스킬 발동 등 적용 조건
- `unit_effects.source_text`: 검수용 원문

현재 초기 데이터에는 방깎·이감 보유 여부만 있고 정확한 수치는 없다. V1 제작 전에 필요한 수치를 한 번 확인해 `unit_effects`에 입력하고, 이후에는 프로젝트 DB에서 직접 관리한다. 원본 사이트와 자동 동기화하지 않는다.

## V1 완료 조건

- 모든 등급과 입력 요소가 한 페이지에 동시에 렌더링되고 게임 중 전체 상태를 훑어볼 수 있다.
- 검색·필터 사용 여부와 관계없이 현재 입력 상태와 전체 등급 배치가 유지된다.
- 허용된 10개 특수 재료만 입력·계산에 포함된다.
- 목재와 골드는 결과에 영향을 주지 않는다.
- 사용자가 재료 또는 등급을 제외하면 모든 조합 후보가 즉시 갱신된다.
- 특수 재료가 필요한 조합이 카드와 재료 트리 양쪽에서 강조된다.
- 방깎·이감 합계가 유닛 증감과 동시에 갱신되고, 미수집 수치가 명확히 구분된다.
- 로그인, 저장, 공유, 메모 진입점이 존재하지 않는다.
