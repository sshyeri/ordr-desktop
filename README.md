# ord local helper

**원피스 랜덤 디펜스 리메이크(ORDR) 조합 도우미 데스크톱 앱.**

게임에서 나온 유닛을 클릭하거나 단축키로 입력하면, 지금 만들 수 있는 조합과 부족한 재료를 실시간으로 계산해 보여줍니다. 브라우저를 오가지 않고 알트탭 한 번으로 확인합니다.

[![최신 릴리즈](https://img.shields.io/github/v/release/sshyeri/ordr-desktop)](https://github.com/sshyeri/ordr-desktop/releases/latest)
[![다운로드](https://img.shields.io/github/downloads/sshyeri/ordr-desktop/total)](https://github.com/sshyeri/ordr-desktop/releases/latest)

> 게임을 자동으로 조작하는 기능은 없습니다. 유닛을 직접 입력하면 조합을 계산해 주는 도구입니다.

## 다운로드

**[👉 최신 버전 받기 (Windows)](https://github.com/sshyeri/ordr-desktop/releases/latest)**

릴리즈 페이지에서 `ord-local-helper-Setup-*.exe` 를 받아 실행하면 됩니다.
설치 후에는 앱이 새 버전을 알아서 확인하고 알려줍니다.

> **처음 실행할 때 "Windows의 PC 보호" 경고가 뜹니다.**
> 코드 서명 인증서를 구입하지 않아서 Windows SmartScreen이 띄우는 경고입니다.
> `추가 정보` → `실행` 으로 넘어가시면 됩니다.
> 이 저장소에 앱 코드가 전부 공개돼 있으니 직접 확인하셔도 됩니다.

## 지원 범위

- **대상 맵: 원피스 랜덤 디펜스 리메이크(ORDR)**
- 등록 데이터: 20개 분류, 유닛·재료 310종
- 지원 운영체제: Windows 데스크톱
- 구 원랜디 11.089 및 다른 개조·파생 맵은 조합식이 달라 정확성을 보장하지 않습니다

## 기능

### 빠른 유닛 입력

- 유닛 이미지나 이름을 왼쪽 클릭하면 보유 수량 +1, 오른쪽 클릭하면 -1
- 흔함 유닛 `Q W E R A S D F G`, 흔함 선택 위습 `V`
- 잘못 입력한 내용은 **최대 50단계까지** 되돌리거나 다시 실행
- 전체 초기화 후에도 바로 이전 상태로 복구
- 유닛·재료 310종이 한 화면에 전부 표시됩니다. 탭 전환, 페이지 넘김, 가상 스크롤을 쓰지 않습니다

### 실시간 조합 계산

- 보유한 중간 유닛과 하위 흔함 유닛을 재귀적으로 계산
- 각 상위 유닛의 조합 진행률과 부족한 최하위 재료 수량 표시
- 흔함 선택 위습은 부족한 흔함 유닛을 대신하는 재료로 계산
- 진행률 80% 이상만 후보에 표시하고, 상위 등급 우선·진행률 내림차순으로 정렬
- 90% 이상과 100% 달성을 색상으로 구분

### 원클릭 조합

- 후보의 `조합 실행` 버튼을 누르면 필요한 재료가 자동으로 차감되고 완성 유닛이 보유 목록에 추가됩니다
- 조합 처리도 되돌리기·다시 실행을 지원합니다
- 특정 재료나 등급을 계산에서 제외해 플레이 방식에 맞게 조정할 수 있습니다

### 상위 조합 경로와 조합 명령어

- `↗` 버튼으로 해당 유닛으로 만들 수 있는 상위 조합을 그래프로 확인
- 그래프를 드래그해 이동하고, 상위 유닛을 눌러 다음 경로를 계속 탐색
- 상세 화면에서 흔함 재료·상위 재료·보유 특성과 함께 **게임 내 조합 명령어**를 확인할 수 있습니다. 채팅창에 바로 입력하시면 됩니다

### 현재 덱 상태 요약

- 보유 중인 상위 유닛을 화면 상단에서 한눈에 확인
- 보유 유닛 기준 **방어력 감소(방깎)·이동속도 감소(이감)** 를 종류별로 합산
- 수치가 아직 확인되지 않은 유닛은 `0`으로 처리하지 않고 `수치 미확인`으로 구분합니다
- 보유 특성을 개수와 함께 모아 보여주고, 특성에 마우스를 올리면 관련 유닛을 강조

### 검색과 스킬 필터

- 이름 검색으로 모든 등급에서 일치하는 유닛을 강조하고 해당 위치로 이동합니다. 목록이 사라지지 않습니다
- 공격력·공격속도 버프, 스턴, 방깎, 이감, 보스 피해 등 스킬 조건으로 유닛을 찾을 수 있습니다
- 같은 항목을 다시 누르거나 `Esc` 로 해제

### 그 밖에

- 도우미 기본 목록에 없는 유닛도 추가해 효과 합계에 반영할 수 있습니다
- 조합 후보 영역의 너비 조절과 접기, 현재 상태 영역 숨기기
- `Ctrl` `+` / `-` / `0` 으로 화면 배율 조절

## 단축키

| 단축키 | 기능 |
|---|---|
| `Q W E R A S D F G` | 해당 흔함 유닛 +1 |
| `V` | 흔함 선택 위습 +1 |
| `Shift` + 유닛 키 | 해당 유닛 -1 |
| `Z` / `Shift + Z` | 되돌리기 / 다시 실행 |
| `T` / `Shift + T` | 전체 초기화 / 초기화 이전 상태 복구 |
| `Ctrl + -` / `Ctrl + +` / `Ctrl + 0` | 축소 / 확대 / 기본 배율 |
| `Esc` | 모달 닫기 또는 선택 필터 해제 |

## 이용 시 참고사항

- 본 프로그램은 게임을 자동 조작하지 않는 별도의 로컬 조합 계산 도구입니다
- 조합 결과는 프로그램에 포함된 데이터 기준이며, 맵 업데이트 직후에는 실제 게임과 일부 차이가 날 수 있습니다
- 조합식이나 명령어가 실제 맵과 다르면 사용 중인 맵 버전, 유닛 이름, 실제 조합식을 함께 제보해 주세요
- 업데이트가 표시되면 최신 버전 설치를 권장합니다

## 릴리즈

`v`로 시작하는 태그를 push하면 GitHub Actions가 Windows 러너에서 빌드해 릴리즈까지 올립니다.

```powershell
npm version patch --no-git-tag-version
git commit -am "vX.Y.Z"
git tag vX.Y.Z
git push && git push origin vX.Y.Z
```

태그와 `package.json` 버전이 다르면 워크플로가 빌드 전에 멈춥니다.
